# SurgCore MCQ Validator v0.3.0

First community-facing release of a free, MIT-licensed offline quality checker for **educational MCQ datasets**.

### Included features

- Python 3.10+ CLI that checks CSV/JSON data, missing answers/options/IDs, exact and heuristic duplicates, references, and explanations.
- Explicit CSV/JSON field mapping for differently named columns.
- Safety checks that preserve meaningful comparisons (for example, `pH < 7.30` vs `pH > 7.30`) and prevent the source bank from being overwritten when saving reports.
- Privacy-first [browser demo](https://surgcore-mcq-demo.pages.dev/) for educators; no Python install, signup, telemetry or upload of question files.
- Reusable [GitHub composite Action](https://github.com/hossamkadasi/surgcore-mcq-validator/blob/main/action.yml) for repository quality gates.

### Download and quick start

- **Python wheel:** download the attached `.whl`, then run `python -m pip install /path/to/wheel.whl` and `surgcore-mcq-validator --version`.
- **Offline browser demo ZIP:** download and extract the attached ZIP, then open `demo/index.html` locally. Choose one of the built-in synthetic examples.
- **Source:** download the automatic GitHub source ZIP/tarball or clone the repository.

### Quality gates

- CI must pass **61 Python unit tests** on Python 3.10 and 3.13, **20 Node.js unit tests**, and both synthetic composite Action fixtures before this release workflow runs.
- Tests and examples are artificial. Passing tests is not evidence of verified clinical accuracy or real-world adoption.

### Privacy and clinical safety

Checks are strictly structural. The tool does **not** determine whether medical questions or answer keys are clinically accurate and cannot replace an educator's review.
Never publish or upload patient information, licensed textbooks, proprietary exam questions, confidential bank exports, or credentials.
