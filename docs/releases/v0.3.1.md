# SurgCore MCQ Validator v0.3.1

This patch release improves the mobile browser experience after a real iPhone pilot revealed that a downloaded validation report was mistakenly selected as an MCQ question bank.

### Changes

- **Saved report viewer:** selecting a previously downloaded `surgcore-validation-report.json` now displays its prior summary and issues without rerunning MCQ checks.
- Clearly marks report-viewing mode, disables `Run local checks` for reports, and re-enables checks when the user switches to a question bank or a synthetic example.
- Provides an Arabic/English explanation adjacent to file selection to distinguish input question banks from output reports.
- Recognizes report content by its JSON structure, not by its filename, validates counts and issue shapes, and uses safe DOM `textContent` rather than HTML interpolation.
- Limits on-screen issue rendering to 200 entries to keep mobile devices responsive. Saved JSON reports remain available locally for detailed review.
- The Python CLI now reports a specific error if asked to validate a previously exported report.
- Added targeted regression tests. All clinical validity limitations still apply.

### Safety

- Reports viewed through the browser reflect **previous findings**, not a new validation or medical answer review.
- No file upload, remote API, analytics, clinical record or proprietary question bank is introduced.
- As with every release, GitHub Actions runs the Python, JavaScript and composite-action suites before producing release artifacts.
